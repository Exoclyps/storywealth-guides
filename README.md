# StoryWealth Guides

Troubleshooting guides for the [StoryWealth](https://www.nexusmods.com/games/fallout4/collections/5atq9t) Fallout 4 collection.

- [Cyclic Rule Issue Fix](guides/cyclic-rule-issue-fix/README.md): Vortex reports cyclic rules or the game crashes after a collection update
- [How to Reinstall the Collection](guides/reinstall-the-collection/README.md): a clean reinstall of the collection

Each guide is a folder with its `README.md` and its screenshots (`01.png`, `02.png`, ...). The Nexus articles are generated from these files, so edit them here.
